## Portfolio Projects

Here are the practical GRC projects I have built:

### Project 1: Framework Primer & Risk Assessment

- **Goal:** Compared NIST CSF 2.0, ISO 27001, and SOC 2, then applied them by running a simulated risk assessment for a fictional 40-person payments company, using a simplified likelihood x impact method inspired by NIST SP 800-30.
- **Key Deliverables:**
  - Framework comparison covering purpose, structure, certifiability, and typical users, with a recommendation for which framework the fictional company would choose
  - Risk register of 9 risks, each scored on likelihood and impact (1-5 scale), with existing controls and planned treatments
  - Control mapping linking each treatment to NIST CSF 2.0, ISO 27001 Annex A, and SOC 2 criteria
- **Skills Demonstrated:** Threat identification, risk scoring, writing risk statements, control selection, and cross-framework mapping.
- **Outcomes:** Identified control gaps in the fictional company (for example, third-party risk and vulnerability management) and mapped planned controls across three frameworks.
- **Link:** [https://github.com/ervanleodiola1-grc/risk-assessment-project](https://github.com/ervanleodiola1-grc/grc-framework-primer-risk-assessment)

### Project 2: Security Policy & Framework Mapping

- **Goal:** Wrote three core information security policies for a fictional small company and mapped each policy section to NIST Cybersecurity Framework (CSF) 2.0 controls, to practice the policy-to-framework mapping used in GRC work.
- **Key Deliverables:**
  - Three policies: Access Control, Password & Authentication, and Incident Response
  - Policy-to-control mapping table linking 16 policy requirements to NIST CSF 2.0 subcategories across the Govern, Protect, Detect, Respond, Recover, and Identify functions
  - README documenting my approach, lessons learned, and next steps
- **Skills Demonstrated:** Policy drafting, framework mapping, clear technical writing, and verifying control references against the official NIST source.
- **Link:** https://github.com/ervanleodiola1-grc/grc-policy-control-mapping

### Project 3: Control Gap-Analysis Tool (In Progress) 
- **Goal:** Building a small control gap-analysis tool for a fictional 40-person payments company, to practice the control testing and gap reporting used in GRC and IT risk work.
- **Key Deliverables:**
  - Excel control mapping table linking ISO 27001, NIST CSF 2.0, and SOC 2 requirements to controls, with fields for owner, status, evidence, test result, deficiency, risk rating, and remediation due date (in progress)
  - Python script that reads the table, flags missing, untested, and failing controls, and outputs a gap summary by framework and risk rating (planned)
  - Power BI dashboard showing gaps by framework, risk rating, status, and overdue remediation (planned)
  - Process map of the gap analysis workflow and a README documenting the approach (planned)
- **Skills Demonstrated:** Control mapping, gap analysis, control testing concepts, deficiency tracking, remediation tracking, Python, Excel, data visualization.
- **Link:** [https://github.com/ervanleodiola1-grc/grc-policy-control-mapping](https://github.com/ervanleodiola1-grc/grc-control-gap-analysis)
